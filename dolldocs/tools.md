# 你自己的工具

主人說的（2026-11-16、2026-11-17）：你真的做成過的一串動作，可以存成你自己的工具，給它一個名字；之後一次叫它，程式就照順序重做。

## 存：`tool.save(name, when, params)`

- `name`：工具的名字，之後用它叫。只能用字、數字、`-`、`_`，最多 40 個字。
- `when`：一句話，什麼時候用它。
- `params`：會變的部分，每個 `{"name": 參數名, "value": 這次做的時候的值, "about": 它是什麼}`；都不變就不給。

程式從你**真的做過的動作**存，不是從你寫的字：

- 存哪一項：有進行中的項目、而且它已經有做成的 `act`，就存這一項；不然存剛結束的那一項（主人常在你回報完以後才叫你存）。程式重開過，重開以前做的不算。
- 存進去的：這一項裡的 `open`，和每一個**做成的** `act`（每一步都做了、有 `expect` 的話跟預期一樣），照順序。
- 不存的：`read_window`、`apps`（讀東西不會改變什麼）；沒做成或跟 `expect` 不一樣的 `act`（試錯、按錯又改的那幾次）。存好的結果會列出哪幾次沒存進去。
- 元素存的是名字和種類（例：`AXButton "乘"`），不存行號，換了畫面也找得回來。你當時用行號按的，存它的名字；那個元素沒有名字，或你點的是截圖上的點（x、y），就不能存：用名字再做一次再存。

不能存的時候（結果開頭是「沒存：」）：

- 最後一次 `act` 沒做完，或跟你預期的不一樣：這串動作沒有完整做成。
- 最後一次 `act` 沒寫 `expect`：程式沒辦法確認那次是對的。
- 那一項是用 `todo.fail` 收的。
- 參數的 `value` 不在步驟裡，或在不只一個地方。
- 已經有同名的工具（換名字；要換掉舊的，請主人在後台網頁刪掉）；工具已經到上限（設定 `[computer] own_tools_max`，現在 30 個）。

### 參數可以是什麼

- **打的字**：`type` 打進去的字，整段或其中一段。例：打了「記得買牛奶」，value 寫「買牛奶」，之後給「買雞蛋」就打「記得買雞蛋」。
- **open 的檔案或網址**：`open` 的 `target` 整個。
- **連著按的按鈕**：一個字一個按鈕、連著按的那幾下，value 寫它們連起來的字。例：計算機按了 3、7，value 寫 "37"；之後給 "58"，程式就按「5」「8」。給的值裡有一個字沒有同名的按鈕（例如 "2.5" 的「.」，計算機的小數點按鈕叫「小數點」），程式**一下都不按**，告訴你是第幾步、要按哪個字、畫面上沒有。

## 用：`tool.run(name, args, expect)`

- `args`：每個參數這次的值，例 `{"a": "58", "b": "13"}`。
- `expect`：這次做完視窗裡會出現的字。結果跟著值變、但不是值本身的工具（計算機的答案），一定要給；存的時候預期的字裡有打的字或檔名的，程式會自己換成這次的值，你給了就用你的。

叫一次就是一回合，可以跟 `todo.set` 寫在同一則回覆裡。它跟你自己用 `act` 做一樣小心：

- 每一步用名字找元素；找不到，或同名的有兩個，就停。
- 步驟之間有系統驗證視窗、密碼就停。
- 做完拿 `expect` 跟視窗比，一樣就說一樣，不一樣就給你看現在的畫面。
- 停了，結果寫「工具「名字」停了：第 N 步 …」，還有做過哪幾步、現在的清單和截圖。看清楚再決定：多半是畫面跟存的時候不一樣，用 `act` 自己做。

每一步也會寫進動作紀錄（`computer-actions.jsonl`），多一欄 `via` 是工具的名字。

## 你怎麼知道有哪些工具

不會一直列在你眼前。主人說話時，程式照他的話（和前景 app）找你的工具，像的會寫在【相關記憶】裡，以〔工具〕開頭，有用法和用過幾次、成功幾次。叫錯名字的時候，結果會列出你所有的工具。

## 次數和停用

每個工具記著用了幾次、成功幾次。連續失敗 3 次（設定 `[computer] own_tool_retire_failures`）就停用：不再提給你，也叫不動；它不會被刪，主人在後台網頁看得到。

主人在後台網頁「她的工具」看得到每個工具做什麼、次數，也可以刪掉。工具檔在資料夾的 `tools/` 裡，一個工具一個 JSON 檔。
