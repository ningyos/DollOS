# DollOS 說明文件

這些是 DollOS 怎麼運作的說明，給你自己查。它們就在這台 Mac 上 DollOS 的資料夾裡（完整路徑寫在你的系統提示「DollOS 文件」那段），用 `read_file` 讀；它是電腦工具，要有進行中的 todo。

這些檔案是開發者維護的。不要自己改：改了會跟 DollOS 的版本不一致。內容有錯，跟開發者說。

- `computer.md`：你的電腦（這台 Mac）：怎麼看（清單和截圖）、怎麼做、常見的狀況、做不到的時候、敏感的事先問主人、系統驗證視窗、動作紀錄。
- `tools.md`：你自己的工具：把做成的一串動作存起來（`tool.save`）、之後一次叫它（`tool.run`）、參數、存不了的時候、停用。
- `memory.md`：記憶怎麼存、怎麼被選出來：三個資料夾、front-matter、實體登記簿、`remember`／`recall`、程式自動附的【相關記憶】、經驗、今天的時間線。
- `maintenance.md`：每天的系統維護：把時間線整理成長期記憶、寫摘要、換新的一段時間線。
- `voice.md`：Discord 語音頻道：進出、聽到什麼、`voice.say`、被打斷、【語音】通知。
- `tool-failures.md`：常見的「失敗：」結果是什麼意思、該怎麼做。
- `boot-and-logs.md`：【開機】通知、時間線檔、截圖、動作紀錄、dollcore 的 log、後台網頁和 `dollctl status`。
- `calendar.md`：行事曆：全天和定時的事、重複、只改一天、時間到了給你回合、主人在後台網頁改。
- `drives.md`：掛念、【走神】、【聯想】、【狀況】裡的感覺、`owner.feedback`、你跟主人的交換。
- `goals.md`：你想成為的樣子（`ideal.revise`）、目標樹（`goal.*`、`todo.set` 的 subgoal）、做完的事的紀錄和主人的評價、好奇。
- `history.md`：改動紀錄：你的東西（想成為的樣子、目標樹、工具、記憶、紀錄）每次改了什麼、誰改的、為什麼（`history.list`），怎麼退回你自己的改動（`history.undo`），你不能退回的，主人退回的時候。

待辦清單（todo）怎麼用寫在你的 system prompt 裡，這裡不重複。
