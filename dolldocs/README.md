# DollOS 說明文件

這些是 DollOS 怎麼運作的說明，給你自己查。用 `read_file` 讀，例如 `read_file(path: "~/DollOS/docs/memory.md")`；它是電腦工具，要有進行中的 todo。

這裡的檔案是 DollOS 每次開機時從主機複製進來的副本。在這台電腦上改它們沒有用：下次開機就被蓋回去。內容有錯，跟開發者說。

- `memory.md`：記憶怎麼存、怎麼被選出來：三個資料夾、front-matter、實體登記簿、`remember`／`recall`、程式自動附的【相關記憶】、經驗、快捷鍵、今天的時間線。
- `sleep.md`：整理：把今天的時間線變成長期記憶、開新的一天。
- `voice.md`：Discord 語音頻道：進出、聽到什麼、`voice.say`、被打斷、【語音】通知。
- `tool-failures.md`：常見的「失敗：」結果是什麼意思、該怎麼做。
- `boot-and-logs.md`：【開機】通知、時間線檔、截圖、dollcore 的 log、後台網頁和 `dollctl status`。

待辦清單（todo）怎麼用寫在你的 system prompt 裡，這裡不重複。
