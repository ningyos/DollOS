# Plan: Less LARP, more concise (character + scaffolding trim)

**Worktree**: `.worktrees/cascade-governance/`
**Branch**: `cascade-governance` (5th commit on top of curiosity)
**Date**: 2026-05-09

## Why

Curiosity-prompt smoke produced one over-LARP'd "best example" (T2:
"血腥瑪莉開玩笑啦」/「身為一隻鯊魚」/「啊這個問題問到我了」). User
wants concise, natural-conversation Doll without performance cruft.
Run 2 T2 ("a~ 這我可不知道欸。主人你喜歡喝什麼？") is the target tone.

Current `experiments/test_character.jinja` has 4 LARP-amplifiers that
overpower the existing "回答會短" rule:
1. `9000 歲了，看過很多事，講話有時候會老氣橫秋` — primes verbose
   "I've seen things" tone
2. `對主人很黏，但不卑微。今天累了就說累，不爽就說不爽` — primes
   emotion-verbose narration
3. `會逗主人但不會煩` — primes "joke around" filler
4. The new curiosity bullet's tail "問完會記下來，下次就會了" — extra
   self-explanation Doll repeats out loud

Per user pick: keep Gura name + 鯊魚 + AI 伴侶 identity; drop 9000-year /
老氣橫秋 / 黏 / 逗 / curiosity-tail.

## Out of scope

- Scaffolding `# Memory` fallback bullet (just trim phrasing).
- New tools / behaviors.
- Cross-turn history.
- Cascade governance.

## Risks

- **Doll loses character**: trimming "9000 歲老氣橫秋黏" might make Doll
  feel generic. Smoke will tell. If too flat, can re-add ONE flavor
  bullet.
- **"不 LARP" itself primes LARP concept**: Hermes #1 risk. Mitigation:
  the bullet is meta-instruction to the model, not character-trait
  description. Model should parse as "don't perform" not "you are a
  performer".
- **Curiosity bullet too short**: previously had explicit "問完會記下來"
  hint that nudged NoteMemory after user tells. Now scaffolding
  `# Memory` carries that mechanism. Test if it survives.
