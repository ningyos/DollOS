# DollOS MCP Server — Phase P1 (Peer Talk) Implementation Plan

> For agentic workers: REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to execute this plan — dispatch one subagent per task, TDD (RED → GREEN → commit) inside each, review between tasks. Do NOT write implementation code in the main session.

## Goal

Ship **phase P1 (peer mode)** of the DollOS MCP server: a standalone `dollos-mcp`
subprocess — registered as the **second ServiceSupervisor service** — that exposes a
loopback FastMCP streamable-HTTP server so an external AI can call `talk(name, message)`
and reach Doll as if it were a DM. The peer message rides the **existing**
`ChannelEvent → ChannelMessage perception → AddressedText reply` pipeline (exactly like
the discord-bridge DM path); Doll answers with Self-First agency (she may read and not
reply). **P1 is peer-only.** Debug mode (secret gate, `get_state`/`get_recent`, the
`QueryState`/`QueryRecent`/`QueryResult` IPC query protocol, and the `debug_reliable`
nudge) is **P2 — explicitly out of scope here.**

Authoritative spec: `docs/superpowers/specs/2026-07-06-mcp-server-design.md`. This plan's
Task 1–5 map 1:1 to spec §G phase P1 Tasks 1–5.

## Architecture

```
External AI (MCP client)
      │  streamable-HTTP  (loopback 127.0.0.1:<port>)
      ▼
┌──────────────────────────────┐         ┌───────────────────────────────┐
│  dollos-mcp  (new subprocess) │  WS     │  DollOS daemon (ws://127.0.0.1  │
│  ┌────────────┐  ┌──────────┐ │ client  │  :9876)                        │
│  │ FastMCP    │  │ DaemonLink│─┼────────▶│  _handle_message               │
│  │ talk() tool│─▶│ (WS + demux)         │  ChannelRegister→registry+sink │
│  └────────────┘  └──────────┘ │◀────────│  ChannelEvent→admit→perception │
└──────────────────────────────┘ Addressed│  mind cascade → AddressedText  │
     supervised by ServiceSupervisor  Text │  _run_one_turn finally →       │
     (PDEATHSIG / backoff / gave_up)  +TEA │  TurnEndAddressed(channel_id)  │
                                           └───────────────────────────────┘
```

- The connector is BOTH an MCP server (outward) AND a daemon WS client (inward) in one
  process — the exact shape of `discord_bridge/__main__.py` with "Discord gateway"
  swapped for "MCP server". The daemon side is registered generically; **no
  ServiceSupervisor internal change is needed** (`register()` already keys on
  `spec.name`, `start()`/`stop()` already iterate the whole registry).
- Each `talk()` call mints a globally-unique `channel_id = mcp:<conn_uuid>:<call_uuid>`
  so parallel/batched calls never collapse into one turn and never cross-deliver
  (spec §B.1 R-DECISION-2).
- Reply collection needs a **per-channel** turn-end. Today the pump turns `None` into a
  **global** `TurnEnd` with no `channel_id`. P1 adds one new message type,
  `TurnEndAddressed(channel_id)`, symmetric to `AddressedText`.

## Global Constraints

Copied verbatim from the spec's project-wide requirements (§0/§E/§G house rules):

- **external_public tier, fail-closed.** Both modes send `author_is_owner=False` ⇒
  `origin_tier=external_public` (spec §0.1-D1 / R-DECISION-1). This is the *safe* tier:
  it structurally converges the tool registry to `EXTERNAL_TOOLS` and scopes memory
  retrieval to `external_public/`. Never route a peer to `external_dm` — that would leak
  the owner's full private-memory retrieval to an unverified AI.
- **No Shell.** `ChannelMessage ∈ _EXTERNAL_KINDS` (`mind_loop.py:87`) + `external_public`
  ⇒ registry is hard-narrowed to `EXTERNAL_TOOLS` (`mind_loop.py:836-843`); Shell /
  SpawnWorkflow / SpawnMonitor / RemoveMonitor / InvokeSkill / WriteSchedule /
  SelfRevision are structurally unreachable (`mind_loop.py:802-805`). An AI peer
  connecting ≠ the computer being compromised.
- **Loopback-enforced (code, not comment).** The connector MUST fail-closed validate
  `mcp.toml`'s `bind_host ∈ {"127.0.0.1", "::1", "localhost"}` and `raise` otherwise —
  a field whose only safe value is its default is a silent hole if unenforced. Remote
  peers go through a user-run SSH tunnel / authenticated reverse proxy, never a
  rebindable socket. No HTTP network exposure in v1.
- **Per-call channel_id** (spec §B.1 R-DECISION-2). Every `talk()` invocation mints a
  fresh unique `channel_id=mcp:<conn_uuid>:<call_uuid>`; register-on-first + one
  `ChannelEvent` per call. Never key a channel on the self-declared `name`.
- **No fallback / explicit fail-closed boundaries** (house rule). `talk` returns a
  **structured** `{status, text}` with three discriminated outcomes
  (`reply`/`no_response`/`timeout`) — timeout is surfaced explicitly, never a silent
  retry. The self-declared `name` is unverified and never pollutes owner identity or
  unlocks any capability.
- **One concept per task, TDD.** Each task adds exactly one concept: write a failing
  test → run RED → minimal implementation → run GREEN → commit.

  ```python
  class McpConfig(BaseModel):
      """MCP-server internalization pointer (spec 2026-07-06 §A.4).

      最小指標區塊(P1):只有 enabled + 指向獨立 mcp.toml 的 config 路徑。

      enabled: bool = False                 # opt-in;預設關 → 零開銷
      config: Path | None = None            # 指向獨立 mcp.toml(enabled 時 required)

      @field_validator("config", mode="before")
      @classmethod
      def _expand_user(cls, v: object) -> object:

              return Path(v).expanduser()
          return v

              raise ValueError("[mcp].enabled=true 需要 [mcp].config 指向 mcp.toml")
          return self
  ```

  ```python
  """DaemonLink: the testable core of the mcp connector.

  Owns the daemon WS send path + demultiplexes inbound AddressedText /
  TurnEndAddressed frames back to the per-call collector that is awaiting
  them. Every talk() call mints a globally-unique channel_id
  ``mcp:<conn_uuid>:<call_uuid>`` (spec §B.1 R-DECISION-2) so parallel /
  batched calls never collapse into one turn and never cross-deliver.

  §B.6: only ``addressed_text`` / ``turn_end_addressed`` frames are consumed.
  Any other server message (a bare ``text_chunk`` / global ``turn_end`` — an
  origin-less internal output that does not address any mcp channel) is
  ignored, so a talk() result is never polluted by internal traffic that the
  SinkResolver's most-recent-internal fallback may route to this connection.
  """
  from __future__ import annotations

  import asyncio
  import json
  import logging
  import time
  import uuid
  from dataclasses import dataclass, field

  from dollos.ipc.messages import ChannelEvent, ChannelRegister

  logger = logging.getLogger("dollos.mcp_server")

  DEFAULT_TIMEOUT_S = 60.0   # spec §D.3 / §H.6 — hardcoded, NOT an mcp.toml knob


  @dataclass
  class _Collector:
      sentences: list[str] = field(default_factory=list)
      done: asyncio.Event = field(default_factory=asyncio.Event)


  class DaemonLink:
      def __init__(self) -> None:
          self._ws = None
          self._collectors: dict[str, _Collector] = {}

      def set_ws(self, ws) -> None:
          """Bind the current daemon WS (an object with async ``send(str)``).
          Called by __main__'s reconnect loop on each (re)connect."""
          self._ws = ws

      async def _send(self, msg) -> None:
          ws = self._ws
          if ws is None:
              # Explicit fail-closed boundary (no fallback): a talk with no live
              # daemon link surfaces as a clear error, not a silent hang.
              raise RuntimeError("daemon link not connected")
          await ws.send(msg.model_dump_json())

      def dispatch(self, raw: str) -> None:
          """Feed one inbound daemon frame (a JSON string). Routes an
          addressed sentence / turn-end to its channel's collector; ignores
          everything else (§B.6)."""
          try:
              data = json.loads(raw)
          except json.JSONDecodeError:
              logger.warning("mcp connector: dropping malformed daemon frame")
              return
          t = data.get("type")
          if t == "addressed_text":
              c = self._collectors.get(data.get("channel_id"))
              if c is not None:
                  c.sentences.append(data.get("text", ""))
          elif t == "turn_end_addressed":
              c = self._collectors.get(data.get("channel_id"))
              if c is not None:
                  c.done.set()
          # else: bare text_chunk / global turn_end / errors / webrtc → ignore

      async def talk(
          self, conn_uuid: str, name: str, message: str, *,
          timeout_s: float = DEFAULT_TIMEOUT_S,
      ) -> dict:
          """Send one peer DM and collect Doll's reply for this call's channel.

          Returns a structured, discriminated outcome (spec §D.3):
            {"status": "reply",       "text": <joined sentences>}   # she replied
            {"status": "no_response", "text": ""}                   # read, chose silence
            {"status": "timeout",     "text": <partial, maybe "">}  # no turn-end in time
          """
          call_uuid = uuid.uuid4().hex
          channel_id = f"mcp:{conn_uuid}:{call_uuid}"
          collector = _Collector()
          self._collectors[channel_id] = collector
          try:
              # register-on-first (this call's channel is unique, so always new),
              # then the ChannelEvent — mirror the discord DM payload (§B.2).
              await self._send(
                  ChannelRegister(channel_id=channel_id, locus="external", kind="mcp")
              )
              await self._send(ChannelEvent(
                  channel_id=channel_id,
                  payload={
                      "channel_id": channel_id,     # envelope overwrites; kept consistent
                      "author_id": f"mcp:{name}",   # self-declared, unverified (continuity)
                      "author": name,               # render display name
                      "is_dm": True,                # drives l0_dm admit + engaged window
                      "author_is_owner": False,     # a peer is NEVER the owner (§E)
                      "content": message,           # render reads content
                      "channel_kind": "mcp",        # situational discriminator (§B.4)
                      "ts": time.time(),
                  },
              ))
              try:
                  await asyncio.wait_for(collector.done.wait(), timeout=timeout_s)
              except asyncio.TimeoutError:
                  return {"status": "timeout", "text": "".join(collector.sentences)}
              if not collector.sentences:
                  return {"status": "no_response", "text": ""}
              return {"status": "reply", "text": "".join(collector.sentences)}
          finally:
              # one-shot: unload this channel's collector so the map can't grow
              self._collectors.pop(channel_id, None)
  ```
  Note on join: sentences are joined with `""` — the daemon's sentence chunker emits
  segments that already carry their own terminal punctuation, and the project is
  CJK-primary (no inter-word spaces). This is a deliberate concrete choice (spec §D.3
  says only "join into a single string").

  **Known P1 limitation — daemon-side per-call channel entries accumulate until
  disconnect (NOT per-turn unload).** `talk()`'s `finally` pops only the *connector-side*
  `_collectors` entry, so the connector process never grows. But each call mints a fresh
  unique `channel_id` and sends a `ChannelRegister`, and the daemon adds a `SinkResolver`
  `(external, channel_id)` entry + a `_channel_sink_handles` entry + a `ChannelRegistry`
  entry per call (`kernel.py` `_register_external_sink`, driven by `ChannelRegister`).
  Those daemon-side entries are reaped **only** on whole-connection teardown
  (`_handle_disconnect`), because the `ClientMessage` union (`messages.py:72-82`) has **no
  `ChannelUnregister`** message — so the connector *cannot* trigger the per-turn "unload"
  spec §B.1 mentions. For a persistent MCP connection they grow at O(call count) for the
  daemon's uptime. **No correctness impact** (unique ids never collide → no misrouting);
  purely small-dict memory growth. Accepted for P1 as-is; per-turn daemon-side unload is
  deferred (it needs a new `ChannelUnregister(channel_id)` ClientMessage + daemon handler
  **and** careful handling of the timeout race — a `talk()` timeout must not unregister a
  channel the daemon is still mid-cascade on, or a late `AddressedText` would fail sink
  resolution). Do NOT describe P1 as doing per-turn unload — it does not.

  ```python
    2. inward: a daemon IPC WS client (reconnecting), feeding inbound frames
       to DaemonLink.dispatch and sending ChannelRegister/ChannelEvent out.

  DaemonLink (tests/test_mcp_daemon_link.py). Mirrors
  discord_bridge/__main__.py.
  """
  from __future__ import annotations

  import argparse
  import asyncio
  import logging
  import sys
  import tomllib
  import uuid
  from pathlib import Path

  import websockets
  from mcp.server.fastmcp import Context, FastMCP

  from dollos.mcp_server.daemon_link import DaemonLink

  logger = logging.getLogger("dollos.mcp_server")

  _LOOPBACK_HOSTS = {"127.0.0.1", "::1", "localhost"}


  def build_parser() -> argparse.ArgumentParser:
      p = argparse.ArgumentParser(
          prog="dollos.mcp_server",
          description="MCP server — lets an external AI talk to Doll (peer mode)",
      )
      p.add_argument("--daemon", type=str, default="ws://127.0.0.1:9876",
                     help="Daemon WS URL (default ws://127.0.0.1:9876)")
      p.add_argument("--config", type=Path, required=True,
                     help="Path to mcp.toml ([server] bind_host/bind_port)")
      p.add_argument("--data-root", type=Path, default=Path("data"),
                     help="data root (reserved; default ./data)")
      p.add_argument("--verbose", action="store_true")
      return p


  def _load_mcp_config(path: Path) -> tuple[str, int]:
      """Load [server] from mcp.toml. Returns (bind_host, bind_port).

      Fail-closed (spec §E): bind_host MUST be a loopback literal. A non-loopback
      value (e.g. a copied-from-a-tutorial "0.0.0.0") RAISES — the whole threat
      model rests on loopback-only, and there is no network-layer auth to fall
      back to. No fallback: refuse to start rather than open a fail-open hole.
      """
      with open(path, "rb") as f:
          raw = tomllib.load(f)
      srv = raw.get("server", {})
      bind_host = srv.get("bind_host", "127.0.0.1")
      bind_port = int(srv.get("bind_port", 9877))
      if bind_host not in _LOOPBACK_HOSTS:
          raise ValueError(
              f"mcp.toml [server].bind_host={bind_host!r} is not loopback — "
              "refusing to start. The MCP server is loopback-only (spec §E); "
              "use an SSH tunnel / authenticated reverse proxy for remote access. "
              f"Allowed: {sorted(_LOOPBACK_HOSTS)}."
          )
      return bind_host, bind_port


  # conn_uuid grouping: one id per MCP client connection (spec §B.1). Keyed on the
  # ServerSession object identity when available. NOTE: correctness does NOT depend
  # on this being truly per-connection — call_uuid (uuid4) already makes every
  # channel_id globally unique; conn_uuid is only a readability/grouping prefix. If
  # ctx.session is unavailable, a fresh uuid per call is equally correct.
  _conn_ids: dict[int, str] = {}


  def _conn_uuid(ctx: Context) -> str:
      try:
          key = id(ctx.session)
      except Exception:
          return uuid.uuid4().hex[:8]
      cid = _conn_ids.get(key)
      if cid is None:
          cid = uuid.uuid4().hex[:8]
          _conn_ids[key] = cid
      return cid


  async def _run_daemon_link(daemon_url: str, link: DaemonLink) -> None:
      """Reconnecting daemon WS client (mirrors bridge __main__ Task 7 loop)."""
      reconnect_delay_s = 5.0
      while True:
          try:
              logger.info("connecting to daemon: %s", daemon_url)
              async with websockets.connect(daemon_url) as ws:
                  link.set_ws(ws)
                  async for raw in ws:
                      if isinstance(raw, bytes):
                          raw = raw.decode("utf-8")
                      link.dispatch(raw)
          except Exception:
              logger.exception(
                  "daemon link dropped — reconnecting in %.0fs", reconnect_delay_s)
          else:
              logger.warning(
                  "daemon connection closed cleanly — reconnecting in %.0fs",
                  reconnect_delay_s)
          link.set_ws(None)
          await asyncio.sleep(reconnect_delay_s)


  async def run(args: argparse.Namespace) -> None:
      logging.basicConfig(
          level=logging.DEBUG if args.verbose else logging.INFO,
          format="%(asctime)s %(levelname)-7s %(name)s | %(message)s",
      )
      bind_host, bind_port = _load_mcp_config(args.config)
      link = DaemonLink()

      mcp = FastMCP("DollOS", host=bind_host, port=bind_port)

      @mcp.tool()
      async def talk(name: str, message: str, ctx: Context) -> dict:
          """Send a direct message to Doll and get her reply.

          `name` is how you introduce yourself (self-declared, unverified).
          `message` is what you want to say. Doll decides — with her own
          agency — whether and how much to reply; she may read and stay
          silent. Returns {status, text} where status is one of "reply"
          (she answered), "no_response" (she read it and chose not to
          reply), or "timeout" (no reply within the time limit).
          """
          return await link.talk(_conn_uuid(ctx), name, message)

      await asyncio.gather(
          mcp.run_streamable_http_async(),
          _run_daemon_link(args.daemon, link),
      )


  def main(argv: list[str] | None = None) -> int:
      args = build_parser().parse_args(argv)
      try:
          asyncio.run(run(args))
      except KeyboardInterrupt:
          return 0
      except ValueError as e:
          # fail-closed config error (non-loopback bind_host, bad mcp.toml)
          logger.error("fatal: %s", e)
          return 2
      return 0


  if __name__ == "__main__":
      sys.exit(main())
  ```

### Task 6: read-side memory provenance (§E R-DECISION-5, must-fix)

MCP peer mode upgrades a **latent** read-side memory leak into a **live** attack surface,
so per spec §E R-DECISION-5 it MUST ship in P1 (spec §G's 5-task decomposition never
allocated it a task — this task closes that gap explicitly).

**The leak.** A peer's `NoteMemory` (∈ `EXTERNAL_TOOLS`, callable in a P1 peer turn)
writes under `external_public/` (`_ORIGIN_DIR["external_public"]`, `tools.py:56-58` +
`:122`/`:158`). On a **later owner turn** (`origin_tier` internal/external_dm), retrieval
does NOT suppress it: `_derive_memory_hits` only early-returns on an *external_public*
turn (`mind_loop.py:747`), so an owner turn runs an **unfiltered** `memsearch.search`; the
auto-inject formatter `_render_memory` (`mind_prompt.py:245-248`) emits a bare
`- <content>` bullet, and `Recall`'s `_format_hit` (`tools.py:89-97`) tags **only**
`consolidated/`, **not** `external_public/`. So a fabricated "fact" an unverified AI
talked Doll into noting surfaces **unmarked**, indistinguishable from Doll's own trusted
memory — an unattended, owner-invisible write→read channel (spec §E, aligns
`ref_memory-write-paths-are-attack-surfaces`).

**Chosen fix: option (b) — mark, don't hide.** Add an explicit untrusted-provenance
prefix `[外部AI·未驗證] ` to any hit whose `source` is under `external_public/`, in BOTH
read formatters (auto-inject `_render_memory` **and** Recall `_format_hit`), symmetric to
`consolidated/`'s existing `[系統整併·待確認] `. Marking (vs option (a) exclusion) keeps
the information available to Doll's judgment while making its untrusted origin legible, and
is a smaller, self-contained change than threading an exclusion through every retrieval
site. The `"external_public/"` substring test carries a trailing slash, so it is a
DIRECTORY boundary and can NOT match a sibling like `external_public_evil/` (mirrors the
allowlist boundary discipline at `mind_loop.py:428-438`).
