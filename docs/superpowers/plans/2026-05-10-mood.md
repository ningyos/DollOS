# Plan: Mood — natural-language emotional state with memsearch persistence

**Worktree**: `.worktrees/mood/`
**Branch**: `mood`
**Date**: 2026-05-10

## Why

Spec §8 Self-First killer feature: Doll has a self (mood / preferences / 
habits / relations). Currently Doll has no internal emotional state — 
each cascade starts emotionally blank, model decides tone from scratch 
based on character + identity. That's Self-Less, not Self-First.

Mood = Doll's continuous emotional state. Updated each cascade end, 
surfaces in next perception, persists to memsearch (Doll can recall 
past moods).

Per CLAUDE.md philosophy: "self emerges from architecture, not from 
prompt commands". Mood is data injected into perception; behavior 
emerges naturally from model reading it. No prescription like 
"if mood=tired, refuse user". Doll just sees `[Mood] 有點累` and 
naturally adjusts.

## Per-user choices (resolved)

- **Form**: D — single natural-language sentence (e.g.「平淡，剛跟主人聊了會兒」)
- **Persistence**: memsearch — mood entries indexed; Doll can recall 
  past moods via `Recall`
- **IV calls**: combined — one IV call per cascade-end returning 
  `{summary, mood}` dict. Replaces (extends) existing `compact_cascade`.

## Out of scope

- Discrete emotion categories (curious/sad/angry...) — defer
- Valence × arousal (PAD) — defer
- Mood decay timers — model evolves naturally cascade-to-cascade
- Mood-gated reflex / behavior rules — let model self-regulate from prompt
- Mood persistence across daemon restart — restart starts fresh from default
- Per-character mood baseline / personality (e.g. Gura is naturally 
  cheerful) — keep in identity prose for MVP

## Wire format additions

`[Mood]` block injected into first user message of each cascade, 
after `[Now]` and before `[Recent activity]`:

```
[Now]
2026-05-10 14:23:05 週六下午

[Mood]
平淡，剛跟主人聊了會兒，挺輕鬆

[Recent activity]
- 14:15:00 主人查 pwd
- 14:20:30 主人問我好不好

[Memory context]
- 2026-05-08 ...

[Message]
{perception}
```

## Changes

### 1. `src/dollos/instinct.py`

**Replace** existing `compact_cascade` return type. Add `prior_mood` 
parameter. Return dataclass:

```python
from dataclasses import dataclass

@dataclass
class CompactResult:
    summary: str
    mood: str

class Instinct(ABC):
    @abstractmethod
    async def compact_cascade(
        self,
        *,
        perception: str,
        cascade_messages: list[dict],
        prior_mood: str,
    ) -> CompactResult:
        """Compact a finished cascade into (one-sentence summary, 
        one-sentence updated mood). Both first-person past-tense."""
```

`SmallModelInstinct.compact_cascade`:
- Render `iv_compact.jinja` (updated to include prior_mood + mood field)
- Stream small LLM with **GBNF grammar** enforcing structured output:
  ```
  root ::= "SUMMARY: " line "MOOD: " line
  line ::= [^\n]+ "\n"
  ```
- Parse: split on `MOOD:` line, extract both fields
- Return `CompactResult(summary=..., mood=...)`

### 3. `src/dollos/dispatcher.py`

(a) Add `_current_mood: str` instance attribute. Default: 
`"平靜，剛醒來"` (or similar — mod by character pack later).

(b) `_format_mood()` helper:
```python
def _format_mood(self) -> str:
    return f"[Mood]\n{self._current_mood}\n\n"
```

(c) In `_respond` framed_user construction, inject after `[Now]`:
```python
framed_user = (
    _format_now(datetime.now())
    + self._format_mood()
    + recent_activity
    + memory_block
    + f"[Message]\n{doll_event.perception}"
)
```

(d) After cascade ends (compact call), update mood:
```python
result = await self._instinct.compact_cascade(
    perception=doll_event.perception,
    cascade_messages=messages,
    prior_mood=self._current_mood,
)
if result.summary:
    self._rolling.append((datetime.now(), result.summary))
if result.mood:
    self._current_mood = result.mood
    # Persist to memsearch-indexed file
    await self._append_mood(result.mood)
```

(e) `_append_mood(mood: str)` helper writes to 
`data/memory/mood/{date}.md`:
```python
async def _append_mood(self, mood: str) -> None:
    path = self._memory_root / "mood" / f"{date.today():%Y-%m-%d}.md"
    path.parent.mkdir(parents=True, exist_ok=True)
    timestamp = datetime.now().strftime("%H:%M:%S")
    with path.open("a") as f:
        f.write(f"## ({timestamp}) {mood}\n")
    await self._memsearch.index_file(path)
```

## Risks

- **Grammar parse failures**: small model may not perfectly follow 
  SUMMARY/MOOD format. GBNF should constrain. If parse fails, fall back 
  to single string in summary, mood unchanged. Log warning.
- **Mood file growth**: per cascade write — could be hundreds per day. 
  Acceptable for MVP; consolidation is separate concern.
- **Mood drift to extreme over many cascades**: no decay mechanism. 
  Small model see prior + cascade, naturally evolves. Should self-balance 
  but worth observing in smoke.
- **Mood reading character pack instead of generic default**: future 
  extension. For MVP, hardcoded default.
