# Plan: Subagent (ephemeral async worker)

**Worktree**: `.worktrees/subagent/`
**Branch**: `subagent`
**Date**: 2026-05-09

## Why

Spec calls Subagent "ephemeral task-specific agent Doll dispatches" + "results re-enter the event queue". Use case: Doll wants to do something that takes time / context (parse logs, search files, multi-step research) without blocking her main turn. She spawns a worker, gets a structured report later as a new turn's perception.

This is the first agentic-extension feature post step-14 stabilization. Doesn't touch core cascade (which is now solid).

## Out of scope

- Drone (persistent / scheduled) — separate, later.
- Subagent recursion (subagent spawns subagent) — explicitly forbidden in MVP.
- Subagent inheriting Doll's full memory / character — subagent has its own minimal context.
- Distributed subagents / over WS — local asyncio only.

## Design (per user clarifications)

- **Result format**: subagent MUST emit a structured `Report` tool call to terminate. The Report's args become the SubagentResultEvent's content. No free-form Say allowed in subagent.
- **Timeout**: per-spawn, set by Doll via `SpawnSubagent(timeout_s=...)`. No default — Doll explicitly estimates.
- **Concurrency**: unlimited asyncio.Tasks. Dispatcher tracks them; canceled on stop.

## Architecture

```
Doll's main cascade:
  emit <tool_call>SpawnSubagent(task="X", timeout_s=60)</tool_call>
        ↓
  SpawnSubagent.run(ctx):
    spawn asyncio.Task(Subagent.run(task, timeout_s))
    add done_callback that fires SubagentResultEvent into dispatcher's event queue
    return f"subagent {id} dispatched (task={task}, timeout={timeout_s}s)"
        ↓
  Doll's cascade continues normally, sees the dispatch confirmation as
  Shell-like tool result. Doll can spawn more, or call Say to user.

Background (parallel asyncio.Task):
  Subagent.run(task, timeout_s):
    asyncio.wait_for(_inner_run(task), timeout=timeout_s)
    on success: SubagentResultEvent(task, status, summary, details)
    on TimeoutError: SubagentResultEvent(task, status="timeout", ...)
    on Exception: SubagentResultEvent(task, status="error", reason=str(e))

  _inner_run(task):
    build sub-cascade messages: [{"role": "user", "content": task}]
    use SUB_TOOLS (no Say, no SpawnSubagent, plus Report)
    use B4-typed grammar generated from SUB_TOOLS
    cascade loop (same-tool 3-fail counter retained)
    when subagent emits Report tool_call:
      Report.run() returns None (side-effect tool)
      no results in this iter → cascade breaks
      extract Report's args from messages, return as result
    cascade ends → return Report args (or "no Report emitted" error)

Dispatcher event queue:
  SubagentResultEvent enters via dispatcher.dispatch(event)
  _perceive renders it as Doll-facing perception:
    "你派出的 subagent 回來了：
     task: ...
     status: ok / timeout / error
     summary: ...
     details: ..."
  Doll's main cascade fires for this new event (new turn)
```

```python
class SpawnSubagent(BaseModel):
    """Dispatch a sub-worker to handle a task in the background. Returns
    immediately with a dispatch confirmation. The result comes back as
    a new turn's perception when the subagent finishes (or times out)."""
    
    task: str = Field(description="What the subagent should do.")
    timeout_s: int = Field(
        ge=1, le=600,
        description="Wall-clock seconds before subagent is killed. "
                    "Estimate based on task complexity (30 short, 300 long).",
    )
    
    async def run(self, ctx: ToolCtx) -> str:
        sub_id = str(uuid.uuid4())[:8]
        # ctx needs a way to access the subagent runner — extend ToolCtx
        ctx.subagent_runner.spawn(
            sub_id=sub_id,
            task=self.task,
            timeout_s=self.timeout_s,
            response_sink=ctx.sink,  # subagent results route to same client
        )
        return f"subagent {sub_id} dispatched (task={self.task!r}, timeout={self.timeout_s}s)"
```

**`Report`** (in SUB_TOOLS only — NOT in main TOOLS):
```python
class Report(BaseModel):
    """Terminate this subagent and report the structured outcome to Doll."""
    
    status: Literal["ok", "incomplete"] = Field(
        description="ok if task completed; incomplete if partially done."
    )
    summary: str = Field(description="One-sentence summary of what happened.")
    details: str = Field(
        description="Findings / output / data Doll asked for. Plain text."
    )
    
    async def run(self, ctx: ToolCtx) -> None:
        # Side-effect: stash Report args into ctx for the subagent runner to pick up.
        # Returning None ends the cascade naturally.
        ctx.subagent_report = {
            "status": self.status,
            "summary": self.summary,
            "details": self.details,
        }
        return None
```

### 3. New module: `src/dollos/subagent.py`

```python
class SubagentRunner:
    """Spawns and tracks subagent asyncio.Tasks."""
    
    def __init__(self, *, dispatcher: EventDispatcher, adapter: LLMAdapter,
                 renderer: PromptRenderer, memory_root, memsearch, transcripts_root):
        self._dispatcher = dispatcher
        self._adapter = adapter
        self._renderer = renderer
        self._memory_root = memory_root
        self._memsearch = memsearch
        self._transcripts_root = transcripts_root
        self._tasks: set[asyncio.Task] = set()
    
    def spawn(self, *, sub_id: str, task: str, timeout_s: int,
              response_sink: asyncio.Queue):
        coro = self._run_with_timeout(sub_id, task, timeout_s, response_sink)
        t = asyncio.create_task(coro, name=f"subagent-{sub_id}")
        self._tasks.add(t)
        t.add_done_callback(self._tasks.discard)
    
    async def _run_with_timeout(self, sub_id, task, timeout_s, response_sink):
        try:
            report = await asyncio.wait_for(self._run_cascade(task), timeout=timeout_s)
        except asyncio.TimeoutError:
            event = SubagentResultEvent(
                subagent_id=sub_id, task=task, status="timeout",
                summary="subagent exceeded wall-clock timeout",
                details="", response_sink=response_sink,
            )
        except Exception as e:
            event = SubagentResultEvent(
                subagent_id=sub_id, task=task, status="error",
                summary=f"subagent crashed: {type(e).__name__}",
                details=str(e), response_sink=response_sink,
            )
        else:
            if report is None:
                event = SubagentResultEvent(
                    subagent_id=sub_id, task=task, status="no_report",
                    summary="subagent ended without calling Report",
                    details="", response_sink=response_sink,
                )
            else:
                event = SubagentResultEvent(
                    subagent_id=sub_id, task=task,
                    status=report["status"],
                    summary=report["summary"],
                    details=report["details"],
                    response_sink=response_sink,
                )
        self._dispatcher.dispatch(event)
    
    async def _run_cascade(self, task: str) -> dict | None:
        """Run a sub-cascade, return Report args or None if Report never called."""
        from dollos.tools import SUB_TOOLS  # avoid circular
        from dollos.llm.templates import build_qwen3_think_tool_grammar
        
        grammar = build_qwen3_think_tool_grammar(SUB_TOOLS)
        system = self._renderer.render("subagent_scaffolding")
        messages = [{"role": "user", "content": task}]
        
        # Sub-context — like ToolCtx but with subagent_report slot.
        ctx = SubagentToolCtx(
            sink=None,  # subagent has no live user sink
            memory_root=self._memory_root,
            memsearch=self._memsearch,
            transcripts_root=self._transcripts_root,
            subagent_report=None,  # Report tool stashes here
        )
        
        # cascade loop, similar to dispatcher._respond but no recall/scaffolding
        # re-render, no rolling buffer, simpler.
        last_failed_tool = None
        consecutive_fails = {}
        
        while True:
            assistant_buf = []
            results = []
            parser = ToolStreamParser()
            
            async for chunk in self._adapter.stream_messages(
                system=system, messages=messages, tools=SUB_TOOLS,
                max_tokens=4096, grammar=grammar,
            ):
                if chunk.text:
                    assistant_buf.append(chunk.text)
                for call in parser.feed(chunk.text):
                    result = await self._dispatch_tool(call, ctx)
                    if result is not None:
                        results.append(result)
                if chunk.done:
                    break
            for call in parser.flush():
                result = await self._dispatch_tool(call, ctx)
                if result is not None:
                    results.append(result)
            
            messages.append({"role": "assistant", "content": "".join(assistant_buf)})
            
            # If Report was called, ctx.subagent_report is set, return it.
            if ctx.subagent_report is not None:
                return ctx.subagent_report
            
            if not results:
                # No tool calls and no Report → cascade ended without Report.
                return None
            
            for r in results:
                messages.append({
                    "role": "user",
                    "content": f"<tool_response>\n{r.detail or '(no output)'}\n</tool_response>",
                })
            
            # Same-tool 3-fail counter (mirror dispatcher).
            for r in results:
                if r.success:
                    consecutive_fails.clear()
                    last_failed_tool = None
                else:
                    if r.tool_name == last_failed_tool:
                        consecutive_fails[r.tool_name] = consecutive_fails.get(r.tool_name, 1) + 1
                    else:
                        last_failed_tool = r.tool_name
                        consecutive_fails = {r.tool_name: 1}
            
            stuck_tool = next((n for n, c in consecutive_fails.items() if c >= 3), None)
            if stuck_tool is not None:
                # Treat as no_report: subagent stuck before reporting.
                return None
    
    async def _dispatch_tool(self, call, ctx) -> ToolResult | None:
        # Mirror dispatcher._dispatch_tool_call but with SUB_TOOLS lookup
        ...
    
    async def stop(self):
        for t in list(self._tasks):
            t.cancel()
        await asyncio.gather(*list(self._tasks), return_exceptions=True)
```

## Risks

- **Subagent loops without Report**: same-tool 3-fail catches; timeout backstops. Returns no_report event.
- **Memory pressure from many concurrent subagents**: each holds own messages list. Unlimited concurrency could OOM in extreme. Acceptable for MVP; cap later if observed.
- **Subagent cancellation race**: dispatcher.stop() must cancel sub-tasks before main tasks. Ensure proper teardown order.
- **Event sink lifetime**: subagent's response_sink is the user's WS sink. If user disconnects mid-subagent, sink is gone. Subagent still completes but SubagentResultEvent dispatch tries to push to dead queue. Need graceful handling.
