# Plan (Phase 1): Doll's daily schedule + pending event awareness

**Worktree**: `.worktrees/schedule/`
**Branch**: `schedule`
**Date**: 2026-05-10

## Why

Currently every Doll cascade is triggered externally (UserTextEvent / 
DiaryEvent / SubagentResultEvent). She has no agency over her own time. 
Per spec event-driven philosophy + Self-First, Doll should plan her day 
and execute autonomously.

Scope: Phase 1 of a 4-phase larger plan (schedule → async tools → 
interrupt-aware Monitor → unified Subagent). Phase 1 builds the schedule 
foundation + pending-event awareness. No tool protocol changes (those 
come in Phase 2).

## Phase 1 scope

A. Doll plans her day via `WriteSchedule` tool
B. Daemon scheduler fires `ScheduledEvent` at scheduled times
C. Bootstrap (deferred to first connection): missing schedule → fire 
   `DailyPlanEvent` for Doll to plan
D. Dispatcher pending-event queue: events that arrive mid-cascade queue + 
   surface as `[Pending]` block at next iter boundary
E. Doll cascades aware of pending events (informational; scaffolding 
   teaches semantics)

## Out of scope (deferred to later phases)

- Async tools / handles / Monitor / Wait / Cancel (Phase 2-3)
- Suspend/Resume formal state machine (Phase 2/3 Monitor handles via 
  interrupt early-return)
- Multi-day schedules / recurring entries / templates
- Reactive replanning during the day (Doll calls WriteSchedule again 
  to overwrite — coarse but works)
- Schedule visualisation UI

### Dispatcher serialization (gap #2 decision)

**Decision: B — only user-driven event types serialize. Internal 
async results stay parallel.**

Rationale: SubagentResultEvent is "result of work Doll started" — 
queueing it makes the user wait artificially. UserTextEvent / 
ScheduledEvent / DailyPlanEvent / DiaryEvent are "new attention demands" 
— serializing prevents racing cascades that interleave mood / rolling 
buffer / cascade log writes.

Implementation:
```python
# Categorize event types
SERIALIZE_TYPES = (UserTextEvent, ScheduledEvent, DailyPlanEvent, DiaryEvent)
PARALLEL_TYPES = (SubagentResultEvent,)

def dispatch(self, raw: RawEvent) -> None:
    if isinstance(raw, SERIALIZE_TYPES):
        if self._active_cascade and not self._active_cascade.done():
            self._pending.append(raw)
            return
        self._active_cascade = asyncio.create_task(self._handle(raw))
        self._active_cascade.add_done_callback(self._on_cascade_done)
    else:  # parallel types
        task = asyncio.create_task(self._handle(raw))
        self._parallel_tasks.add(task)
        task.add_done_callback(self._parallel_tasks.discard)
```

### `dollos.schedule` module

```python
@dataclass
class ScheduleEntry:
    time: time  # datetime.time
    intent: str


@dataclass
class Schedule:
    entries: list[ScheduleEntry]


def load_schedule(path: Path) -> Schedule | None:
    """Returns None if file missing."""
    if not path.exists():
        return None
    with path.open("rb") as f:
        data = tomllib.load(f)
    entries = []
    for raw in data.get("entry", []):
        # Accept both TOML native time and string ISO (gap #6):
        t = raw["time"]
        if isinstance(t, str):
            t = datetime.fromisoformat(f"1970-01-01T{t}").time()
        entries.append(ScheduleEntry(time=t, intent=raw["intent"]))
    return Schedule(entries=entries)


def write_schedule(path: Path, entries: list[ScheduleEntry]) -> None:
    """Atomic write via temp + rename."""
    path.parent.mkdir(parents=True, exist_ok=True)
    tmp = path.with_suffix(".toml.tmp")
    with tmp.open("w") as f:
        f.write(f"# {date.today().isoformat()}\n\n")
        for e in entries:
            f.write(f"[[entry]]\n")
            f.write(f'time = "{e.time:%H:%M:%S}"\n')
            f.write(f'intent = """\n{e.intent}\n"""\n\n')
    tmp.rename(path)


def due_entries(
    schedule: Schedule, now: datetime, fired: set[time]
) -> list[ScheduleEntry]:
    """Pure function: entries whose time has passed but not yet fired.
    
    Past entries that are already past 'now' but never fired (e.g. daemon 
    was offline) are SKIPPED (gap #7) — only fire entries in the current 
    or near-future minute window.
    """
    return [
        e for e in schedule.entries
        if e.time not in fired
        and now.time() >= e.time
        and (
            datetime.combine(now.date(), e.time) >= now - timedelta(minutes=1)
            # Only fire if entry was scheduled within last 1 minute — 
            # past entries from earlier in the day are skipped.
        )
    ]
```

`due_entries` is pure → easy unit test (gap #8).

### Scheduler runner (gap #8 testable)

```python
# kernel.py
async def _schedule_runner(self) -> None:
    fired_today: dict[date, set[time]] = {}
    while not self._shutdown.is_set():
        try:
            await asyncio.wait_for(self._shutdown.wait(), timeout=30)
            return
        except asyncio.TimeoutError:
            pass
        
        today = date.today()
        path = self._memory_root / "schedule" / f"{today:%Y-%m-%d}.toml"
        schedule = load_schedule(path)
        if not schedule:
            continue
        
        now = datetime.now()
        fired = fired_today.setdefault(today, set())
        for entry in due_entries(schedule, now, fired):
            fired.add(entry.time)
            sink = self._active_sink_or_dummy()
            self.dispatcher.dispatch(ScheduledEvent(
                entry_time=entry.time,
                intent=entry.intent,
                response_sink=sink,
            ))
```

Dummy sink helper: returns a never-read Queue if `self._active_sink is None`.

### `WriteSchedule` tool (gap #3 — also memsearch index)

```python
class ScheduleEntryArg(BaseModel):
    time: str = Field(
        description="ISO HH:MM:SS, 24-hour clock. e.g. '07:30:00'.",
    )
    intent: str = Field(
        description="One short sentence describing the planned action.",
        min_length=1,
    )

    @field_validator("time")
    @classmethod
    def parse_time(cls, v: str) -> str:
        # Validate but keep as str; toml writer parses again.
        try:
            datetime.fromisoformat(f"1970-01-01T{v}")
        except ValueError as e:
            raise ValueError(f"time must be HH:MM:SS, got {v!r}") from e
        return v


class WriteSchedule(BaseModel):
    """Write today's schedule. Replaces any existing schedule for today.
    
    Each entry has a time (HH:MM:SS, 24-hour) and intent (short sentence).
    Past times are NOT fired retroactively — they're skipped by the scheduler.
    """
    
    entries: list[ScheduleEntryArg]
    
    async def run(self, ctx: ToolCtx) -> str:
        from dollos.schedule import ScheduleEntry, write_schedule
        
        today = date.today()
        path = ctx.memory_root / "schedule" / f"{today:%Y-%m-%d}.toml"
        parsed = [
            ScheduleEntry(
                time=datetime.fromisoformat(f"1970-01-01T{e.time}").time(),
                intent=e.intent,
            )
            for e in self.entries
        ]
        write_schedule(path, parsed)
        
        # Also write markdown summary into shared memory for Recall
        # (gap #3).
        md_path = ctx.memory_root / "shared" / f"{today:%Y-%m-%d}.md"
        md_path.parent.mkdir(parents=True, exist_ok=True)
        timestamp = datetime.now().strftime("%H:%M:%S")
        with md_path.open("a") as f:
            f.write(f"\n## 計劃 ({timestamp})\n\n")
            for e in parsed:
                f.write(f"- {e.time:%H:%M:%S} — {e.intent}\n")
        await ctx.memsearch.index_file(md_path)
        
        return f"Schedule written: {len(parsed)} entries"
```

Add to `MAIN_TOOLS` (not SUB_TOOLS — scheduling is main-Doll-only).

## Risks

- **Connection lifecycle race**: handle hooks may interleave with 
  message processing. on_connect runs BEFORE first message handled, 
  on_disconnect AFTER last. Acceptable.
- **Atomic write across filesystems**: `tmp.rename(path)` requires same 
  filesystem. `data/memory/schedule/` is on same fs as tmp. Fine.
- **Daemon offline recovery**: missed scheduled events are dropped. 
  Acceptable; documented in tool description.
- **Doll spammy schedule**: she could plan 100 entries/day. No cap. 
  Acceptable; scheduler iteration is cheap.
- **WriteSchedule race during scheduler read**: scheduler reads 
  schedule.toml every 30s; WriteSchedule replaces it atomically (temp + 
  rename). Race window <1ms.
- **Pending injection oscillation**: Doll iter sees pending → emits 
  Say → cascade ends → pending fires → that cascade sees no pending → 
  good. No oscillation.
